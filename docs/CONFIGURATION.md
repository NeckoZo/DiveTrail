# 配置说明

首次运行用「设置」填写游戏昵称。昵称用于确认采集身份和区分本地档案，固定队友是当前设备上的统计名单。

| 设置 | 用途 |
|---|---|
| 昵称和固定队友 | 当前档案、录入本人判定及队友统计。对局详情仍保存实际队伍。 |
| 赛季、赛段和自动切换 | 当前统计范围。自动切换按本地时间表执行；没有已确认的未来日期时保留当前范围。 |
| 游戏优先、自动采集结算 | 游戏优先会把局内 OCR 延后。1.0 的自动切页暂停。采集仍会读取实际停留的页面。 |
| 调试状态和登录启动 | 显示采集状态悬浮窗，或随 Windows 登录启动。 |
| 结算音效 | 选择一段音色试听，可分别选择进入赛后、总结已读取和 RP 已核验时播放。 |
| 减少界面动效、首页英雄卡 | 控制页面过渡、数值和轨迹动效，以及首页英雄卡的显示。 |
| 定期清理截图 | 清理到期的采集图片，战绩记录继续保留。重要原图可以另行备份。 |

设置保存在当前数据目录的 `matches.sqlite3`。如果旧版提供了已核实的本地赛季时间表，程序保留兼容读取。1.0 的设置页不提供导入时间表入口。

应用没有运行时 API 密钥或 `.env`。OCR 线程相关变量 `OMP_NUM_THREADS` 和 `OPENBLAS_NUM_THREADS` 默认设为 `1`，系统已设值会保留。

## 备份与迁移

`.matchlog` v2 便携备份保存对局、分数校准、档案快照和现存截图，也会带上仍有原图的待处理截图、已确认的头像样本和本地赛季日程。旧版 v1 文件仍可导入；新备份请用 0.7.0 或更高版本恢复。

在新电脑上安装应用，从「设置 → 本地数据 → 导入备份」选择文件。重复的战绩和头像保留本机版本，已有的本地日程也优先。备份时正在识别的截图恢复为待处理。皮肤、未确认的头像、已经清理的原图和 WebView 缓存不随便携备份迁移。若需要逐文件保留这些内容，关闭应用后复制整个 `data/`。

诊断日志、截图和队友昵称都可能含个人信息。分享复现材料前检查这些内容。
