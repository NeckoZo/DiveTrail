# 发布检查清单

1. 更新 `ui/changelog.json` 和界面版本标记，运行 `tools/build_changelog.py`。
2. 核对发布源码有明确许可，排除用户数据、日志、样本原图、密钥和私有 Git 历史。公开打包始终传入 `--public`。
3. 运行 [开发指南](DEVELOPMENT.md) 中的检查；试装 EXE 与解压 ZIP，确认首次说明、独立数据、备份导入和卸载边界。
4. 计算安装版和便携版的 SHA-256，从 GitHub Releases 草稿上传，检查名称与下载链接。标记为稳定版后检查官网与应用的更新提示。
5. 查看发行包的签名状态。在未签名的版本中如实说明 Windows 可能出现运行提示。
6. 在实际排位中复核大厅、总结和经验值识别；记录未覆盖的分辨率、游戏语言和需要补拍的边界。
