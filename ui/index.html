使用说明

  1. 全自动识别

    首次建立档案后，DiveTrail 会自动读取 Apex 前台的排位大厅、开局倒计时、局内快照、赛后总结、经验值页的 RP，以及个人数据页。打完可以切到总结和经验值页，补齐本局数据。

  2. F8 手动补拍

    想补拍总结或分数时，在对应的 Apex 页面按 F8。

  3. 听音效确认进度

    总结已读取、RP 已核验时会按设置播放提示音。可在「设置 → 采集与音效」试听并选择提醒时机。

  4. 暂停或退出

    窗口右上角的 × 会收起到 Windows 托盘。在设置里暂停或继续记录，右键托盘图标可完全退出。

  5. 遇到问题

    在 描述遇到的问题。漏记或错记时，附上大致对局时间和当时看到的游戏页面。
